# Chromatic Atlas of Art — Artwork Database
# Format: HUE | SAT | BRI | Title | Creator | Type
#
# HUE: 0–360  (theme axis)
#   0   = Violence       — pure, fetishized, Tarantino-esque
#   30  = Action         — fight response, war films, manliness
#   60  = Teamwork       — ensemble, sports films, coordination
#   90  = Comedy/Advent  — chaos, errors, lighthearted quest
#   120 = Justice/Dipl   — courtroom, moral plays, Star Trek
#   150 = Mystery/Surr   — Columbo, unraveling, the uncanny
#   180 = Science        — man vs. nature/physics, inquiry
#   210 = Exploration    — flight response, finding one's place
#   240 = Isolation      — solitude, the lone figure, aloneness
#   270 = Longing        — dark romance, yearning, the absent
#   300 = Love           — happy romance, belonging, warmth
#   330 = Sex/Passion    — erotic charge, desire, the body
#
# SAT: 0–100  (intensity)
#   0   = slice of life / no dramatic stakes
#   100 = maximum intensity
#
# BRI: 0–100  (realism)
#   0   = stark documentary realism
#   100 = pure myth / legend / fable
#
# Lines beginning with # are ignored.
